## 📂 Aapko Kaun Kaun Si Files Upload Karni Hain?

Aapke LMS portal par accepted file types hain: **.csv, .pdf, .docx**.  
Aapke folder `LMS_Submission_Files/` mein sabhi required files ready hain:

| # | File Name | Format | Purpose / Deliverable |
|---|---|---|---|
| 1 | `dataset.csv` | `.csv` | 5,000 rows ka cleaned & pre-processed agent execution traces dataset (with 3.9% realistic anomalies) |
| 2 | `data_dictionary.csv` | `.csv` | Sabhi 7 columns ka complete descriptive documentation |
| 3 | `Project_Report.pdf` (or `.docx`) | `.pdf` / `.docx` | Complete 10-page Technical Project Report (Meets minimum 8 pages requirement) |
| 4 | `EDA_Analysis_Report.pdf` (or `.docx`) | `.pdf` / `.docx` | Exploratory Data Analysis report with 5 statistical charts & metrics |
| 5 | `Ethical_Compliance_Declaration.pdf` (or `.docx`) | `.pdf` / `.docx` | Signed Ethical Compliance Declaration (Human-in-the-loop & tool safety) |

*(Note: Aap chahein toh `.pdf` upload karein ya `.docx`, dono accepted hain. Best practice ke liye `.pdf` aur `.csv` directly upload karein).*

## 🚀 Portal Par Submit Karne Ka Step-by-Step Tarika:

1. Chrome browser mein apna LMS submission page kholein:
   `https://university-lms.career-shaper.com/mod/assign/view.php?id=774231&action=editsubmission`
2. Apne Mac par Finder kholein aur is path par jayein:
   `/Users/luvensharma/Desktop/studyplanner/LMS_Submission_Files/`
3. In 5 files ko select karke drag karein:
   - `dataset.csv`
   - `data_dictionary.csv`
   - `Project_Report.pdf`
   - `EDA_Analysis_Report.pdf`
   - `Ethical_Compliance_Declaration.pdf`
4. LMS ke **"You can drag and drop files here to add them"** box mein drop kar dein.
5. Files upload hone ke baad neeche blue button **"Save changes"** par click karein.
6. Aapka project successfully submit ho jayega!
